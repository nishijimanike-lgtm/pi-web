# Pi Web 桌面版本设计文档 (Rust + Tauri v2)

**日期**: 2026-10-11  
**状态**: Approved  

---

## 1. 目标与背景

为了让 Pi Web 拥有更原生、便捷的桌面体验，本项目在原有 Web 体系基础上引入基于 **Rust** 与 **Tauri v2** 的桌面版本。
桌面端承载主 Web 视图，同时提供原生窗口管理、系统托盘常驻、无感后台守护以及安全可靠的 Node.js 进程生命周期管理。

---

## 2. 核心架构设计

```
┌────────────────────────────────────────────────────────┐
│                   Tauri v2 Desktop App                 │
│                                                        │
│  ┌──────────────────────────┐  ┌────────────────────┐  │
│  │     Webview2 Window      │  │ System Tray (托盘) │  │
│  │ (加载 http://localhost)  │  │  (显示/隐藏/退出)  │  │
│  └─────────────▲────────────┘  └─────────▲──────────┘  │
│                │                         │             │
│  ┌─────────────┴─────────────────────────┴──────────┐  │
│  │           Rust Core (src-tauri)                  │  │
│  │  - 端口探测 (Port Probing 30141)                 │  │
│  │  - Node.js 子进程守护与优雅退出生命周期管理      │  │
│  │  - 窗口事件监听 (拦截关闭 -> 隐藏到托盘)         │  │
│  └───────────────────────┬──────────────────────────┘  │
└──────────────────────────┼─────────────────────────────┘
                           │ 启动/管理
                           ▼
          ┌──────────────────────────────────┐
          │  Node.js Backend (Pi-Web 核心)   │
          │  - Next.js Web 界面 & API        │
          │  - Pi AgentSession In-Process    │
          └──────────────────────────────────┘
```

### 关键组件职责
1. **WebView 宿主 (Tauri v2 / WebView2)**：
   - 渲染项目现有的 Next.js 前端界面。
   - 保留全部现代 Web 特性（SSE 流式输出、CodeMirror 高亮编辑器、实时文件树等）。
2. **Rust Core (src-tauri)**：
   - **端口探活 (Port Probing)**：检查 `127.0.0.1:30141`。
   - **Node 子进程管理**：未启动时自动拉起 Node 服务；退出时联动销毁，避免孤儿进程。
   - **托盘与窗口生命周期**：处理最小化至托盘、托盘右键菜单响应、窗口隐藏与重显。

---

## 3. Node.js 服务生命周期管理

1. **就绪检测**：
   - 尝试与 `127.0.0.1:30141` 建立 TCP 握手。
   - 若端口开放，直接将窗口加载至 `http://127.0.0.1:30141`。
2. **自动拉起**：
   - 若端口未占用，Rust 执行启动命令（开发环境运行 `npm run dev`，生产打包后调用 `node server.mjs`）。
   - 每 500ms 进行健康检查（HTTP GET `http://127.0.0.1:30141`），成功后完成加载。
3. **Windows 进程树防孤儿机制 (Job Object)**：
   - 使用 Windows 内核 `Job Object`（配置 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`），将启动的 Node.js 及其子进程绑定至当前应用进程树。
   - 无论桌面端正常退出、崩溃还是由任务管理器强制结束，Node 进程均保证同步被操作系统回收。

---

## 4. 窗口与托盘交互规范

1. **窗口设置**：
   - 默认尺寸：`1280 x 840`，最小尺寸：`800 x 600`，居中启动。
   - 标题：“Pi Web”。
   - 拦截 `CloseRequested` 事件：点击窗口右上角“X”不退出，自动 `window.hide()` 隐藏至系统托盘。
2. **托盘菜单 (System Tray)**：
   - 图标：使用项目现有的 Pi 图标资源。
   - 单击托盘图标：切换主窗口“显示 / 隐藏”状态并获得焦点。
   - 托盘右键菜单项：
     - `显示主窗口 (Show Window)`
     - `在浏览器中打开 (Open in Browser)`
     - `重启后台服务 (Restart Node Service)`
     - `--- (分隔线)`
     - `彻底退出 (Quit)`：触发退出逻辑，清理子进程并退出应用。

---

## 5. 项目工程集成

1. **目录结构**：
   - 新增 `src-tauri/` 目录存放 Rust 源码、`Cargo.toml` 与 `tauri.conf.json`。
2. **依赖与脚本**：
   - 添加 `@tauri-apps/cli` 至 `devDependencies`。
   - 在 `package.json` 添加以下运行脚本：
     - `tauri:dev`: 启动桌面端并对接 Next.js 开发服务。
     - `tauri:build`: 构建 Windows 独立安装包与可执行文件。
